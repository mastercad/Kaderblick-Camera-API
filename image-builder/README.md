# Kaderblick Camera OS

Das Laufzeit-Image basiert auf dem bootfähigen Minimal-Stage von Raspberry Pi OS Bookworm 64-bit. Es enthält keinen Desktop und installiert beim ersten Start nichts aus dem Internet. Kamera-API, USB/UVC-Unterstützung, GPIO, Audio, FFmpeg, SSH und Samba sind bereits enthalten. OpenCV wird als Headless-Paket ohne GTK-, Qt- und Desktop-Abhängigkeiten eingebaut; Kernel-Header, der auf dem Raspberry Pi 5 nicht benötigte generische Pi-Kernel und der umfangreiche `raspi-config`-Werkzeugbaum werden gar nicht erst installiert.

Das gleiche Image ist für SD-Karten und USB-Massenspeicher vorgesehen. Der eigene zweistufige Kaderblick-First-Boot-Dienst vergrößert zuerst die Root-Partition, startet einmal neu und erweitert danach das ext4-Dateisystem auf den gesamten verfügbaren Datenträger, beispielsweise eine 1-TB-USB-SSD. Erst anschließend laufen die individuelle Konfiguration und die Camera-Dienste an.

Der erste Start liest `kaderblick-config.json` aus der FAT-Bootpartition, richtet Konto, Hostname, statische Ethernet-Adresse und SMB ein und entfernt anschließend die Konfigurationsdatei. Für Ethernet läuft das schlanke `systemd-networkd`; NetworkManager und Netplan werden nicht installiert. Kamera und API warten beim Start nicht auf Internet oder einen Gateway. `fake-hwclock` bewahrt ohne NTP eine näherungsweise Uhrzeit für plausible Aufnahmezeitstempel. WLAN und Bluetooth sind deaktiviert. Die Paketinstallation erfolgt ohne empfohlene Zusatzpakete; nur während des Image-Baus benötigte Werkzeuge wie `pip`, `venv` und `raspi-config` werden vor dem Export entfernt. Nicht benötigte Hintergrunddienste für NTP, NetBIOS, Display-Backlight, Bluetooth und automatische EEPROM-Aktualisierung sind ebenfalls deaktiviert; SMB über TCP/IP bleibt über `smbd` vollständig verfügbar.

Das Image wird reproduzierbar vom Workflow `.github/workflows/build-camera-image.yml` erzeugt. Die verwendete pi-gen-Version ist dort auf einen konkreten Commit festgesetzt.
